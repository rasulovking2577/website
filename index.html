FAQ

Остались вопросы?

Сколько стоит сайт? +

Стоимость зависит от задачи, количества блоков и необходимых функций. После короткого обсуждения я называю конкретную стоимость до начала работы.

Сколько времени занимает разработка? +

Простой сайт можно сделать за несколько дней. Более сложный проект занимает больше времени. Срок согласовываем заранее.

Можно ли сделать сайт для моего бизнеса? +

Да. Сайт можно разработать для кафе, салона, барбершопа, мастерской, специалиста, магазина и других небольших бизнесов.

Сайт будет работать на телефоне? +

Да. Адаптивная версия входит в разработку. Сайт проверяется на разных размерах экранов.

Что если у меня уже есть сайт? +

Можно сделать редизайн, улучшить мобильную версию, структуру, скорость и отдельные блоки без полного создания сайта с нуля.
