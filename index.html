Как я работаю

Я самоучка из Махачкалы — превращаю изучение веб-разработки в сайты для реальных заказчиков, а не в учебные примеры.

Изучаю HTML, CSS и JavaScript не по курсам ради сертификата, а на настоящих задачах: беру проект и разбираюсь по ходу дела, если чего-то не знаю. Каждый сайт я веду от первого созвона до рабочей ссылки — без передачи фрилансерам и без шаблонных конструкторов.

Мне важен не масштаб, а результат: сайт должен грузиться быстро, нормально выглядеть на телефоне и решать задачу бизнеса — привести заявку, показать меню, дать записаться.

Вопросы

Частые вопросы

Сколько по времени делается сайт?

Зависит от объёма: простая визитка — несколько дней, лендинг с интеграциями — дольше. Сроки называю после обсуждения задачи.

На чём сделан сайт — на конструкторе?

Нет, чистый код: HTML, CSS и JavaScript. Это даёт больше контроля над скоростью загрузки и внешним видом, чем шаблонные конструкторы.

Нужен ли мне домен и хостинг?

Можно разместить сайт бесплатно (например, на GitHub Pages) или подключить ваш домен — обсудим, что удобнее для вашей задачи.

Что если после запуска нужно что-то поправить?

Мелкие правки после запуска — по договорённости. Пишите в WhatsApp, обычно отвечаю в течение дня.

Работаете только с Махачкалой?

Нет, работаю удалённо с заказчиками по всей России — вся коммуникация идёт по звонку и WhatsApp.
